2Bit ALU

The 2-bit ALU project highlights the foundational concepts of digital circuit design and lays the groundwork for building more advanced computational units. The ability to modify and expand the design to handle more bits or additional operations makes it a valuable learning tool in the field of computer architecture and digital electronics.

Smart Plant Watering System

The Smart Plant Watering System project combines sensor technology and automation to make plant care more efficient and effective. Not only does this system reduce water waste, but it also ensures that plants are consistently well-cared for. By providing users with easy control and monitoring, it makes plant maintenance convenient, even for those with limited time or knowledge.

WEB Change Theme

The WEB Change Theme project aims to develop a theme-switching feature that allows users to personalize their website experience based on their preferences or environmental conditions. This feature not only enhances the user experience (UX) but also makes the website more flexible, adapting to different user needs and situations.

WEB Login

The WEB Login project is designed to create a secure and efficient login system for websites. By verifying user credentials and managing access based on roles, the system ensures that only authorized users can access protected content. Through the use of encryption, session management, and secure password storage, the project aims to protect user data and improve the overall security of the website.
